# Installare il sito web invece dell'app mobile nativa

Wiki Copilot usa una PWA del sito `web/` per iPhone e Android, non l'app React Native in `mobile/`. Così la versione installata riusa la chat e le regole del sito; usare l'app nativa richiederebbe un secondo prodotto da adattare e distribuire. Decisione: [#7](https://github.com/LiliumStargazer/wiki-copilot/issues/7).
