# Verificare le rimozioni Wiki.js prima di modificare l'indice

Il prune nativo di Onyx tratta gli ID assenti dall'inventario come pagine da rimuovere. Wiki.js può restituire un inventario incompleto anche senza un errore: per questo teniamo disabilitato il prune nativo e richiediamo una verifica puntuale di unpublish, uscita dallo scope, move o `PageNotFound` prima di ogni rimozione. Non applichiamo una soglia quantitativa alle rimozioni verificate. Se cambia il valore di visibility, rimuoviamo il vecchio documento anche quando la nuova versione non si indicizza: la riservatezza prevale sulla disponibilità. Decisione: [#3](https://github.com/LiliumStargazer/wiki-copilot/issues/3).
